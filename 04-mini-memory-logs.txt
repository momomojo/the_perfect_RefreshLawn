Stripe & Supabase Integration Audit Report & Rework Plan
Date: 2025-06-17
Scope: Review & fix Expo app's Stripe integration (Edge Functions, Webhooks, DB schema, migrations, frontend) vs. live Supabase DB.

--- CORE ISSUES ---
1.  **Missing Migrations:** `customers`, `subscriptions`, `payments`, `invoices` tables exist live but have no local CREATE migrations.
2.  **Inconsistent Customer ID:** `profiles.stripe_customer_id` and `customers` table used inconsistently.
3.  **Duplicate Function Logic:** Monolithic `stripe-api` vs. microservices (`stripe-customer-api`, etc.).
4.  **API Version Mismatch:** Stripe API versions differ between functions/webhooks.
5.  **Webhook Idempotency:** Raw INSERTs risk duplicates on retries.
6.  **Sensitive Logging:** Webhook secret exposure.
7.  **Frontend Issues:** Empty `headers` override in invoke, missing `billing_details`.
8.  **Status Confusion:** `booking.status` enum/values mismatch live DB; overlap with payment statuses.
